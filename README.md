# 茶路・陳惠玲茶農營運儀表板展示版

這是提供陳惠玲與茶路共同確認手機介面、訂單流程、廣告呈現方式及品牌建議內容的公開靜態展示站。

## 資料界線

- 首頁與廣告頁可切換最近 7 天、最近 30 天、本月及近一年；預設顯示本月。
- 營業額、有效訂單、平均客單、趨勢與商品彙總，來自 TF2 歷史訂單加上 2026-08-27 的最新 1Shop 同步資料。
- 同一訂單若同時存在於歷史庫與最新同步，以最新 1Shop 資料為準；公開快照只保存彙總。
- 訂單頁的姓名、電話、地址與訂單編號全是虛構示範內容。
- 廣告欄來自 Meta API 的每日活動彙總，並依四個期間同步切換；不含權杖、廣告素材或平台不可變 ID。
- 建議頁會先標示三種決策狀態：1Shop 訂單可作為實際成交依據、Meta 資料可做平台內方向判斷、跨來源回本與擴量仍需補齊訂單對應、匯率、成本與目標 CPA。
- 廣告建議不再使用跨帳戶通用的成本門檻；每張建議包含判斷對象、資料可信度、替代解釋、禁止動作、觀察期與停止條件。
- 素材測試卡會提出彼此真正不同的角度、固定變數與主張界線；目前只有活動總計，因此不會假裝已經找到單則素材贏家。
- 專案不包含顧客個資、Meta 權杖、本機資料庫或平台不可變 ID。

## 本機預覽

直接以任一靜態 HTTP 伺服器開啟此資料夾即可；網站不需要建置步驟或第三方套件。
