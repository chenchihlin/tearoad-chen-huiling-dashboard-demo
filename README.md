# 茶路・陳惠玲茶農營運儀表板展示版

這是提供陳惠玲與茶路共同確認手機介面、訂單流程、廣告呈現方式及品牌建議內容的公開靜態展示站。

## 資料界線

- 營業額、有效訂單、平均客單、月份趨勢與商品彙總，來自 2025-08-01 至 2026-07-31 的 TF2 歷史訂單。
- 173 筆是排除 5 筆取消單後的有效訂單；全部訂單為 178 筆。
- 訂單頁的姓名、電話、地址與訂單編號全是虛構示範內容。
- 廣告欄來自 Meta API 的 2025-08-01 至 2026-07-31 活動彙總；公開檔只含每月數字，不含權杖、廣告素材或平台不可變 ID。
- 專案不包含顧客個資、Meta 權杖、本機資料庫或平台不可變 ID。

## 本機預覽

直接以任一靜態 HTTP 伺服器開啟此資料夾即可；網站不需要建置步驟或第三方套件。
